E-mail Spoofer

One of the first things I made while learning PHP, during the opening lecture on it. It was a form that sent an e-mail with whatever sender name and address you typed in, using PHP's mail() function.

It needed a mail server behind it, so it didn't make the move to the new static site. The original source is still on GitHub.
